# C++ Memory Manager Simulator
To simulate how dynamic memory allocation works internally in an operating system, using C++ to implement allocation algorithms, memory block management, and fragmentation handling.

## Overview
This project simulates dynamic memory allocation mechanisms
such as First Fit and Best Fit strategies.

## Objective
To understand how heap memory allocation works internally
by implementing a simplified memory manager in C++.

## Features
- Dynamic memory block management
- First Fit allocation
- Best Fit allocation
- Memory deallocation
- Defragmentation

## Concepts Used
- OOP
- Linked List
- Strategy Pattern
- Pointers
- Dynamic Memory
